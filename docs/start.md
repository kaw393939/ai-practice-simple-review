# Start here

Improve a working app with AI: add one helpful sentence below its Note box. The task is deliberately small so you can focus on agreeing a plan, reviewing AI edits, and checking the result.

**New to this exercise? [Follow the README](https://github.com/kaw393939/218_spec#readme).** It takes you through creating your copy, terminal cloning, and running the app. Then it sends you to the assignment. No API key is needed.

**Already have your copy running and Git access checked? [Continue to Your first change](./practice).** Keep that folder; do not create another copy.

Use ChatGPT desktop to discuss, Codex to edit the local project, VS Code to inspect files, and terminal Git to keep your work.

The link library is our shared demonstration. Later, use the same process for your class project: IS117's T-shirt site, IS218's calculator, or IS373's hosted Docker/CI/CD site. The [worked example](./example) and [background](./background) are optional reading.
